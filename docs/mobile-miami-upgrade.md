# Телефон, Miami и независимые серверы

## Выбор карты и запуск

В меню выберите **Night Highway** или **Miami Night**. Явный `?map=highway|miami` имеет приоритет над сохранённым `tcu.map`; без обоих используется Highway. Переключение перезагружает страницу, не подменяет дорогу под работающим прогнозом. Оно убирает прежний `?server=`; переключение solo/online сохраняет карту, собственный сервер и диагностические параметры. `?test` по-прежнему использует Highway.

Обе карты имеют онлайн и одиночный режим (`?solo&map=miami`). Highway solo остаётся бесконечной процедурной дорогой; Miami solo использует своё кольцо. Лучший одиночный результат и выбранное небо хранятся отдельно по картам; серверные solo/online-таблицы тоже раздельны.

Локально нужны **два отдельных процесса**, а не два имени одного мира. В отдельных терминалах (пример для Bash):

```bash
MAP_ID=highway PORT=8787 DB_PATH=data/traffic.db RADIO_DIR=data/radio npm run server
MAP_ID=miami PORT=8788 DB_PATH=data/miami/traffic.db RADIO_DIR=data/miami/radio npm run server
npm run dev
```

В PowerShell переменные задаются перед запуском через `$env:MAP_ID='miami'`, `$env:PORT='8788'` и аналогично для путей. Порт по умолчанию **8787 для любого MAP_ID**: для второго процесса задайте 8788 явно. Vite по умолчанию направляет корневые backend-маршруты на 8787, а `/miami/ws`, `/miami/health`, `/miami/api/*` — на 8788, снимая префикс. Другие адреса задаются `GAME_SERVER` / `GAME_MIAMI_SERVER`.

В сборке адреса выбираются через `VITE_ONLINE_URL` и `VITE_MIAMI_ONLINE_URL`, либо `?server=wss://host/prefix/ws`. Соседние HTTP API и health сохраняют префикс (`https://host/prefix/api`, `…/health`). Клиент и сервер проверяют карту, её ревизию и rules hash; неверная карта отвергается. Reconnect-токен привязан к нормализованному адресу и карте.

## Что представляет собой Miami

Это отдельный дорожный профиль, а не перекраска Highway: 12 000 м, четыре одинаковых геометрических четверти по 3 000 м с поворотом 90° каждая. Четыре 3-км района оформления: прибрежный Art Deco, causeway, marina и тоннель. Есть своя тема `miami-night`, пальмы вне отбойников, ступенчатые здания, cyan/pink-неон, вода и мосты с подъездными эстакадами. Оформление повторяется на следующем круге. Это стилизованная трасса, не географическая реконструкция города.

Сервер создаёт один неизменяемый мир `MAP_ID=highway|miami`. В Compose процессы используют один образ, но разные тома: `game_data` и `miami_data`. SQLite и каталог радио проверяют принадлежность карте. Старую заполненную БД/радиокаталог без метки можно принять только как Highway; Miami требует отдельного хранилища. Сохраняйте оба тома и аудиокаталоги при обновлении. Плейлисты, тюнинг, модерация, журнал и рекорды одного мира не распространяются на другой.

Для прямого сервера `TRUSTED_PROXIES` пуст: XFF не доверяется. Compose задаёт доверие только фиксированному socket-IP Caddy на `client_proxy`, а не всему subnet; неверный allowlist останавливает запуск. Админский аудит остаётся socket-only. Политика адресов, сетевые overrides и безопасная stopped-service миграция SQLite/WAL/радио в `/var/lib/traffic` описаны в [deploy.md](deploy.md).

## Телефон и полный экран

- Телефонный интерфейс включается при coarse pointer или ширине до 760 CSS px. Меню прокручивается, учитывает safe area; пауза компактнее. Это не отдельный графический пресет: качество, материалы и текстуры не понижаются из-за тача.
- Во время езды слева — полоса руля, ручник и «Нитро» (буст), справа — газ и тормоз/R; сверху — пауза, камера, скорость/передача и fullscreen. В ручной коробке появляются сцепление и −/+. Наклона устройства для руления нет.
- Касания независимы и поддерживают несколько пальцев. Отмена указателя, потеря захвата, скрытие страницы, смена ориентации и открытие меню освобождают удерживаемые кнопки.
- Большой HUD, таблица игроков и аудиопанели скрыты во время телефонной езды; ошибки соединения/модели остаются видимыми. В меню и паузе радио/микшер доступны в «Радио и звук».
- «Полный экран» запрашивает нативный fullscreen для всей страницы с DOM-кнопками непосредственно по нажатию. Браузерный Esc/системный выход остаётся главным. Поворот в landscape запрашивается только при поддержке, без гарантии.
- Если fullscreen недоступен или запрещён, включается **только компактный режим страницы** с явным сообщением. Подсказка iOS предлагает «На экран Домой»; это не доказательство работы нативного fullscreen на физическом iPhone.
- На клавиатуре сохраняются **Shift — BOOST, Ctrl — CLUTCH**, V — камера, C — задний вид, P/Esc — меню паузы.

## Шины, звук и граница физики

Общий read-only слой `src/presentation/tyres.ts` рассчитывает скорости контактов в порядке FL/FR/RL/RR и использует доступные фактические omega: четыре колеса R34, осевые omega остальных динамических моделей. У совместимого Grip без динамики колёс обороты выводятся из контактной скорости — блокировка не выдумывается из нажатого тормоза. Нормальные нагрузки для эффектов оценочные, а не новая подвеска.

Колёса рисуются с независимым вращением; дым и следы возникают у скользящих контактов, включая burnout и задний ход. Для эффектов есть ограниченные пулы; они не меняют силы, состояние для rewind или управление. Четыре шинных аудиоголоса смешивают качение, scrub и блокировку. Тоннели используют три заранее созданных синтетических стерео-IR банка с плавным переходом по длине/глубине, фильтрацией и ранними отражениями; радио не проходит через этот тракт. Это не измеренные IR реальных тоннелей.

**Протокол 12:** запись удалённого водителя занимает **36 байт**, включая **8 байт** для четырёх signed int16 omega, масштаб **16** (шаг 1/16 рад/с, насыщение ±2047.9375 рад/с). Это телеметрия наблюдателя, не замена полного состояния своей машины. Угол передних колёс передаётся как фактический угол / 1.1 для всех кузовов. Трафик — 26 байт на машину. Старый клиент нужно обновить вместе с сервером.

Единственная разрешённая последняя правка физики: R34 `gripFront=1.22`, `gripRear=1.07`, `longGrip=1.10`. После неё **вся физика заморожена**, включая C63/M156, другие машины, общие контакты и контроллеры. `tests/frozenPhysics.test.ts` фиксирует файлы и пресеты; переснимать хеши ради ревью или оптимизации нельзя.

Настройки имеют `r34Revision=4`. Для revision 3 миграция **по каждому полю** заменяет только точное старое значение: `1.16 → 1.22`, `0.93 → 1.07`, `1.04 → 1.10`. Любое отличающееся пользовательское значение и остальные поля остаются. Для отсутствующей ревизии/1/2 заменяется устаревший пресет R34 целиком. Остальные машины/скорости трафика сохраняются; отсутствующий C63 добавляется отдельно.

Известное замечание ревью физики: таймер ручного переключения в общей Grip-модели может уменьшаться дважды за шаг. Это **report-only**, не исправление в данном обновлении: заморозка запрещает менять физику или подгонять хеши ради этого замечания.

## Админка

Открывайте `/admin.html?map=highway` или `/admin.html?map=miami`. Запросы идут соответственно в `/api/admin/*` или `/miami/api/admin/*`; токены раздельны. После входа карта ответа проверяется до разрешения изменений. Админка намеренно не использует произвольный игровой `?server=`.

Шесть вкладок: **Обзор и игроки / Трафик / Тюнинг / Радио / Лидерборд / Журнал**. Стрелки, Home/End перемещают фокус. Переключение вкладок сохраняет DOM, несохранённые значения форм и текущую загрузку; фильтры таблицы/журнала независимы. Последняя вкладка запоминается для этого сервера и логина. При смене сервера несохранённые формы/загрузка требуют подтверждения; это не обещание сохранения черновика после перезагрузки.

Solo API имеет отдельный суммарный бюджет: 120 валидных записей со счётом от 1000 за скользящую минуту на API-instance, с буфером максимум 120 timestamps; per-address ограничение действует отдельно. Это rate limit, **не ограничение lifetime-размера БД**. Respawn ограничен одним принятым запросом на водителя за секунду симуляции и backpressure.

## Что проверено, а что нет

По результатам интеграционной приёмки, переданным координатором: unit-тесты, typecheck и обе сборки проходят; два реальных prefixed smoke-подключения и интегрированные Edge-проверки игры, админки и мобильного интерфейса прошли. Browser-сценарии находятся в `tests/*.browser.mjs`; они запускаются отдельно от `npm test` и требуют локального Playwright/браузера. Это локальные проверки, не факт выкладки.

**Известный сетевой предел:** измеренный стресс со stalled contacts при 150 мс дал максимальную коррекцию **2.639 м** (ранее округлялось до 2.64 м; p95 около 35 см). Rewind и сглаживание не устраняют непредсказуемые столкновения и паузы доставки. Это не скрывается успешными тестами и не считается гарантией плавности на любой сети. Число — результат конкретного синтетического прогона, не универсальная верхняя граница.

Docker daemon в этой среде недоступен: реальное `compose up`, Caddy/TLS и откат контейнеров ещё не подтверждены исполнением. Удалённого деплоя/push не было. Прослушивание человеком, физический iOS и сопоставимый FPS-бенчмарк реального телефона остаются непроверенными. Старые числа и заметки в профильных документах помечены как исторические; они не переаттестуют новую сборку.
