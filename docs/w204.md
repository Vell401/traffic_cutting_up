# Mercedes-Benz C63 AMG W204

Перенос комплектации `c63amg_dorest.pc` из `mods_to_convert/MercedesW204`.
В меню автомобиль доступен как **Mercedes-Benz C63 AMG W204** (кузов №4),
с отдельной физикой №5. Выбор кузова автоматически выбирает его физику.

## Что подключено

- Дорестайлинговый кузов, салон, стандартные 18-дюймовые колёса; окраска,
  вращение колёс, фактический угол передних колёс и руль, фары, стопы и поворотники.
- Задний привод, семиступенчатый автомат, передаточные числа исходного мода,
  главная пара 3.231, отсечка 7200 об/мин, номинальные 610 Н·м / 336 кВт.
  Масса 1800 кг взята из метаданных мода и остаётся приближением.
  JBeam адаптирован к собственной симуляции игры, а не перенесён как soft-body движок.
- 32 оригинальные записи двигателя и выхлопа M156 (4 089 792 байта),
  смешивание по оборотам и нагрузке, фильтрация в салоне. SHA-256 и источник
  каждого клипа указаны в `public/audio/w204/manifest.json`.
- Выбор и сохранение настроек, административный тюнинг, клиентское предсказание,
  серверная симуляция и отображение машины других игроков.
- Рабочие штатные стрелки скорости/оборотов, LCD скорости и передачи,
  поворотники, свет и ручник. Индикация TC/ESP использует доступное состояние систем.
- Контрруление в заносе при клавиатурном управлении, без добавления скрытых сил к кузову.

Модель: `public/models/mercedes-w204.glb` — **21 045 480 байт / 20.07 MiB**, 234 632 треугольника. Прежние 11.37 MiB относились к экспорту до восстановления внешнего вида и заменены этим размером.
Подробности сборки, материалы, замены отсутствующих деталей, координаты
и контрольные рендеры: [w204-model.md](w204-model.md).

Пресеты двигателя/шин и значимые исходные модели сохранены; C63 дополнительно получил клавиатурное контрруление и исправленную ручную КПП. Управление: **Shift — BOOST, F — CLUTCH**. Общие шинные эффекты/вращение используют доступные осевые omega без изменения сил; протокол передаёт четыре omega наблюдателю и фактический угол колёс всех кузовов. Доступны обе независимые карты и телефонное управление: [mobile-miami-upgrade.md](mobile-miami-upgrade.md).

## Ограничения проверки

Топливо и температура не симулируются и остаются статическими; динамические фонари заднего хода не подключены.
Отсутствующие служебные звуки из базовых банков BeamNG заменяются существующими
эффектами игры. Некоторые отсутствующие базовые материалы и детали имеют
приближённые замены, перечисленные в документации модели.

**Историческая заметка конвертации:** контрольные рендеры получены из конечного GLB,
но та сессия не поддерживала просмотр изображений, поэтому тогда браузерная
визуальная приёмка, прослушивание и FPS оставались непроверенными.
Текущая интеграционная Edge-проверка включает C63 на телефонной Miami (вход,
UI, газ/отмена касания, пауза), но не означает человеческого одобрения материалов
или аудио. Прослушивание человеком, физический iOS и сопоставимые FPS-замеры
по-прежнему не выполнены; Docker/удалённой выкладки также не было.
Приборка проверена на конечном GLB и в headless Edge, включая компиляцию шейдеров.
Прослушивание и замеры FPS на реальном GPU остаются отдельной проверкой.

## Воспроизведение и проверки

Для модели используйте команды из `w204-model.md`; для звуков:

```sh
python3 scripts/prepare-w204-audio.py
npm test -- tests/w204Model.test.ts tests/w204Physics.test.ts tests/w204Audio.test.ts tests/playerView.test.ts
npm run typecheck
npm run build
npm run build:server
```

Тесты проверяют GLB и его декодирование, трансформации колёс/руля, сохранность
звуковых записей, разгон и устойчивость, торможение, воспроизводимость физики,
сохранение настроек и идентичность W204 в онлайн-сессии.
Тесты используют готовые файлы из репозитория и не требуют исходного мода:
SHA-256 записей проверяется по манифесту, а таблицы оборотов — по зафиксированным
ожидаемым значениям. При наличии `mods_to_convert/MercedesW204` дополнительно
проверяются побайтовое совпадение с исходными WAV и контрольные суммы исходников.
Сам исходный мод нужен для повторной конвертации командой `prepare-w204-audio.py`.
