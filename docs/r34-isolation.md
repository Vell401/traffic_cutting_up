# Граница изменений R34

Откат `d5eb624` вернул отменённую работу к `7a9a0c2`. Затем в `main` появился
параллельный `f85f366` («911 Physics changed»). Пользователь явно выбрал сохранить
его. Первоначальной основой стал `4ed6c0b`, содержащий этот Porsche-update
и отдельный фикс переключения машины при переподключении.

Перед разрешённой пользователем публикацией сохранён свежий коммит коллеги
**`2e1ef96`** («fix continuous tire slip physics»). Это текущий эталон остальных
машин: его `vehicleDrift.ts` переносится без изменений. Контрольные хеши исходников
и траекторий сняты независимо в чистой рабочей папке именно этого коммита.

После отказа от самодельного четырёхконтактного прототипа расчёт шин заменён
портом TMeasy из Project Chrono, а за основу клавиатурного руля взят Sketchbook.
Закреплённые версии, границы портирования и лицензии: [r34-foundation.md](r34-foundation.md).

## Что менять запрещено

- `src/config.ts` и исходные значения `carTune`.
- `src/sim/vehicle.ts`, `vehicleDrift.ts`, `vehicleMercedes.ts`, `vehiclePorsche.ts`.
- Уравнения общих столкновений в `src/sim/contact.ts`.
- Модели, материалы и камеры A45/Porsche; файлы GLB в `public/models/`.
- Схемы и сохранённые пользовательские настройки машин `1`, `3`, `4`.

`tests/unchangedCars.test.ts` проверяет исходники, ассеты, камеры, исходные параметры
и контрольные траектории A45/Porsche. `tests/r34Isolation.test.ts` дополнительно
защищает точные схемы/значения глобальных настроек Grip/A45/Porsche и сохранение
пользовательских значений при замене только пресета R34.

Проверка защищённых исходников относительно выбранной пользователем версии:

```powershell
git diff 2e1ef96 -- src/config.ts src/sim/vehicle.ts src/sim/vehicleDrift.ts src/sim/vehicleMercedes.ts src/sim/vehiclePorsche.ts src/sim/contact.ts public/models
```

Вывод должен оставаться пустым.

## Разрешённая интеграция

- Фабрика ID `2` выбирает отдельный `R34Car`; ветви A45/Porsche остаются прежними.
- Только R34 получает новые поля управления шинами и автоподруливанием.
  Диапазон большого выворота расширен исключительно для формы R34.
- При загрузке старых настроек заменяется только `cars['2']`. Остальные машины
  и трафик сохраняются без подстановки дефолтов. Повторный запуск сохраняет уже
  настроенный новый R34.
- В сетевых снимках только кузов R34 передаёт фактический угол передних колёс.
  Кодирование остальных машин не меняется.
- Обновление салона и управление его ресурсами подключены через необязательные
  функции, которые возвращает только сборщик R34.

Физическая приёмка новой модели отделена от этих проверок:
`tests/r34ForceAcceptance.test.ts` проверяет причинность сил, сохранение импульса
без сцепления, работу рулевой рейки, пробуксовку и передачу веса. Прежние тесты
«нужного угла заноса через N секунд» не являются критерием реалистичности.
