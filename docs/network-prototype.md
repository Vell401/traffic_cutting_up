# Этапы 2–3: дорожная сеть и большая заготовка

## Запуск

```sh
npm run dev
```

- Большая карта: http://localhost:5173/network.html
- Технический участок: http://localhost:5173/network.html?layout=prototype
- WASD / стрелки — управление; R — возврат на парковку; 1–3 — выбор ветки следующей развязки. Без выбора используется продолжение маршрута, поворот руля в зоне решения выбирает ответвление.

Онлайн запускается отдельным процессом:

```sh
npm run server:network
```

Открыть http://localhost:5173/network.html?layout=bay&online=ws://localhost:3011 в нескольких окнах. Сервер по умолчанию слушает loopback; фабрика `createNetworkSandboxServer` принимает host/port, CLI поддерживает `NETWORK_PORT`. После сборки: `node dist-server/networkSandbox.js`.

Это технический вход этапов 2–3. Меню основной игры, рекорды, админка, выбор парковки в интерфейсе и общая карта участников относятся к этапу 4.

## Архитектура

- `src/network/geometry.ts`: направленные рёбра, явная связность, горизонтальная длина, высота, уклон, кривизна, переменное число полос и границы поверхности.
- `src/network/layout.ts`: небольшой прототип и большая сеть варианта 02. Встречные проезжие части разделены и расположены для левостороннего движения. Геометрическое пересечение не создаёт соединения.
- `src/network/driving.ts`: адаптер существующих машин, непрерывные переходы между координатными системами, выбор ветки по её дальнейшему расхождению, возврат задним ходом через фактический вход.
- `src/network/traffic.ts`: движение по графу, учёт лидеров за стыками и слияний, пространственный отбор соседей.
- `src/network/session.ts`: единый детерминированный шаг 120 Гц для одиночного режима и сервера; полные снимки состояния, безопасное размещение, контакты в мировых координатах с отсечением разных уровней.
- `src/network/render.ts`: базовое полотно, разметка, ограждения, мостовые опоры, оболочки тоннелей, парковки, вода, берега и объёмы районов; плавающий render-origin и отбор чанков.
- `server/networkSandbox.ts`: отдельные авторитетные миры прототипа и большой карты, WebSocket, снимки 10 Гц. Браузер интерполирует мировые положения; локальное предсказание онлайна пока не подключено.

Старые `Road`, игровой протокол и модели физики сохранены. Сетевой адаптер границ действует только на созданных им экземплярах машин. Машина следует поверхности в 2.5D; прыжки и полная трёхмерная динамика не реализованы.

## Большая сеть

580 направленных рёбер, 548 узлов. Основные оси: R0 — 36 км, C1 — 7,8 км, C2 — 8,8 км, C3 — 2,5 км, S1/S2/S3 — по 3,7 км; суммарно **66,2 км без рамп и парковочных подъездов**. Все направленные проезжие части вместе с рампами и доступами дают **177,3 км**, это другая метрика, показываемая в техническом HUD.

Включены J1–J6, направленные связи X1, альтернативный F4, локальные расширения, P1/P2/P3, мост, подводный и городские тоннели. Рампы ограничены проектным уклоном 8%. Детали движения X1 и размеры являются рабочими решениями для прототипа, а не результатом пользовательского теста.

## Проверки

Выполнены:

- `npm run typecheck`;
- `npm test`: **1067 passed, 8 skipped**, 105 файлов прошли, один пропущен;
- `npm run build`;
- `npm run build:server`;
- headless Chromium/WebGL: обе карты открываются без JS-исключений, газ увеличивает скорость и положение, отдельный онлайн-мир принимает игрока и движение;
- WebSocket integration: несколько клиентов, изоляция миров, отключение, входные данные, восстановление снимков;
- геометрия: направленная достижимость, стыки/касательные, уклоны, расстояние встречных частей, разные высоты пересечений;
- движение: все профили машин, переходы, обратный ход, выбор реальных веток, безопасный общий спавн/reset, контакты разных уровней, распределение и начальная непересекаемость трафика, детерминированный replay;
- старые проверки неизменности физики проходят без обновления закреплённых хешей;
- замер Node на текущей машине: 100 машин трафика + игрок, 1200 шагов / 10 секунд мира — около **0,90 мс/шаг**. Это замер симуляции, не FPS браузера и не бюджет ПК пользователя.

## Границы доказательства

Скриншоты браузерного прогона сохранены во временный каталог; модель не смогла их прочитать. Визуальная читаемость всех развязок, отсутствие артефактов на всех стыках и полный ручной проезд 66,2 км не подтверждены. Контакты пока упрощённые: остановка/откат пересекающихся машин, а не полный обмен импульсами основной игры. Геометрический тест достижимости не заменяет длительный игровой проезд каждого съезда. Длительное поведение плотного трафика, задержки сети и FPS на целевом ПК ещё требуют проверки. Этапы 2–3 реализованы как техническая версия; окончательная приёмка геометрии и качества остаётся открытой.
