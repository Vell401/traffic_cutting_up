# Traffic Cutting Up

Браузерный мини-симулятор ночного cut up по хайвею: проезды впритирку к трафику, комбо и множитель. Удар о машину заканчивает заезд, лучший результат сохраняется.

Сейчас готовы **фазы 0–6 из [PLAN.md](PLAN.md)**: играбельный прототип, мир вокруг дороги, директор трафика, очки с HUD, визуал (модели машин, постобработка, искры, камеры) и звук.

- **Кнопка Test** справа сверху в меню (или `?test` в адресе) открывает тестовый режим со списком видов трассы слева:
  - каждый тип участка, рамы с указателями, путепровод, оба тоннеля, большой мост и «всё подряд»;
  - выбор кликом или клавишами 1–0;
  - каждый показ короткий и заканчивается блоками поперёк дороги, машина плавно останавливается сама, R начинает показ заново;
  - кнопки трафика ставят «стенку» или колонну, включают режимы с грузовиками и плотный трафик, выключают трафик совсем;
  - рекорды не сохраняются.
- **Графика Medium/High** выбирается в меню и запоминается. High: DPR до 2, MSAA 4×, текстура дороги 2048, анизотропия 16, чёткие указатели.

Дорога чередует участки:
- **открытый** — фонари, деревья, город за отбойником;
- **шумозащитные стены**;
- **эстакада** — земля в 11 м ниже, город вокруг и под ней;
- **тоннель** — ряды ламп на потолке, порталы, холм сверху;
- **большой вантовый мост** над водой — подсвеченные H-образные опоры, веера вант, гирлянды огней, панорама берегов. На мост можно попасть только с эстакады, и за ним снова эстакада.

Фонари бывают натриевые (оранжевые) и LED (белые). Ещё попадаются рамы с указателями и путепроводы над дорогой.

Трафиком управляет директор:
- **Сложность растёт с дистанцией заезда.** Примерно к 8 км трафик в 1.8 раза плотнее, а «грубых» водителей вдвое больше. Удар сбрасывает сложность вместе с заездом.
- **Каждый ~1 км меняется режим:** обычный, `LIGHT TRAFFIC`, `HEAVY TRAFFIC`, `TRUCK CONVOY` (грузовики заходят и во вторую полосу), `ROADBLOCKS` (три машины в ряд, одна полоса свободна) и `PLATOONS` (3–5 машин бампер к бамперу).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173  (?debug — сразу открыть панель тюнинга)
npm test           # тесты физики, дороги, коллизий и очков
npm run build      # typecheck + production-сборка в dist/
```

## Управление

| Клавиша | Действие |
|---|---|
| W / S (↑ / ↓) | газ / тормоз |
| A / D (← / →) | руль |
| R | вернуться на полосу (заезд заканчивается) |
| C | камера: погоня, дальняя, капот, бампер |
| M | звук вкл/выкл |
| P / Esc | пауза |
| ` | панель тюнинга и счётчики FPS/GPU |
| F1 | метрики: FPS, мс кадра, симуляции, рендера и GPU, draw calls, память, трафик, участок |

Геймпад: левый стик — руль, RT/LT — газ/тормоз, Start — пауза, Y — на полосу.

## Очки

- Выше 100 км/ч очки капают за скорость.
- **Near miss** — проезд с боковым зазором меньше 1 м. Чем ближе и быстрее, тем больше очков; за грузовик ×1.5.
- **Lane split** — проезд между двумя машинами в соседних полосах.
- Каждый проезд продлевает комбо (4 с) и поднимает множитель.
- Касание отбойника сбрасывает комбо, удар о машину заканчивает заезд.

## Устройство

```
src/
  config.ts      все настраиваемые параметры (их же правит панель тюнинга)
  core/          цикл, ввод, события, математика
  sim/           симуляция без three.js: дорога, машина, трафик, коллизии, очки
  render/        three.js: дорога чанками, трафик на инстансах, камера, небо
  ui/            HUD и панель тюнинга
tests/           vitest
```

Ключевые решения описаны в [PLAN.md](PLAN.md). Коротко:

- Дорога задаётся профилем кривизны (радиусы от 1200 м). Всё считается в координатах дороги `(s, d)`.
- Машина — bicycle model с упрощённой шинной моделью. Автоподруливания нет: после перестроения машину выравниваешь сам. Руль с клавиатуры прогрессивный: короткий тап даёт малый угол для подруливания, удержание за ~0.15 с доводит до полного. Отпущенный руль быстро возвращается в центр. Ассистов два:
  - стабилизация рыскания (`yawAssist`): вращение следует за рулём и гаснет, как только руль в центре, поэтому перестроение заканчивается ровно;
  - трэкшн-контроль (`tractionControl`) убирает тягу так, чтобы задней оси хватало сцепления на поворот, и на газу машина не срывается в занос.
- Трафик ездит по IDM и меняет полосы по упрощённому MOBIL, перед манёвром включает поворотник.
- Симуляция идёт с фиксированным шагом 120 Гц, рендер интерполирует между шагами. Мировые координаты сдвигаются к нулю (floating origin), чтобы не терялась точность float32.
- Каждый 100-метровый чанк рисуется 4–6 склеенными мешами. Буферы чанков переиспользуются, поэтому во время езды нет ни аллокаций, ни новых GPU-буферов.
- Окна города рисует шейдер, текстур нет. Несколько настоящих точечных источников перескакивают между ближайшими к машине фонарями, остальной свет — пятна-декали.
- Все шейдеры компилируются до первого кадра, чтобы не было фризов, когда новый объект впервые попадает в кадр.
- Машины процедурные: боковой силуэт выдавливается с фаской, стёкла и пластик зашиты в цвет вершин. Один тип машины — один инстанс-меш, весь трафик рисуется примерно за 12 draw calls.
- Звук целиком синтезируется через Web Audio, сэмплов нет:
  - **Двигатель:** гармоники от оборотов, впуск и мягкий перегруз; отсечка, провал на переключении, хлопки при сбросе газа.
  - **Турбина:** свист и стравливание.
  - **Окружение:** ветер и гул шин от скорости, визг при заносе, гул шумовых полос, скрежет об отбойник.
  - **Трафик:** свист проезда с панорамой в сторону машины, гул машин рядом.
  - **Удары и интерфейс:** звуки ударов, сигналы near miss по нарастающей пентатонике, конец комбо и заезда, новый рекорд.
  - **Тоннели:** эхо, свёртка с синтезированной импульсной характеристикой.
- Постобработка (`postprocessing`) работает в HDR: MSAA 4×, блум только для источников ярче белого, тонмаппинг ACES, цветокоррекция через процедурную 3D-таблицу цвета (LUT), виньетка. Хроматическая аберрация включается на высокой скорости и на проездах впритирку.
